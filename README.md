# Performance Gear Server

## Live link: https://performance-gear-server.vercel.app/

This is the backend server for the **Performance Gear** sports equipment e-commerce platform. The server provides a RESTful API for managing and retrieving sports equipment data. It is built with Node.js, Express, and MongoDB.

## Features

- **Fetch All Equipments:** Retrieve all available sports equipment.
- **Limited Equipment Fetch:** Retrieve a limited number of items for display.
- **Equipment Details:** Get detailed information about a specific equipment item.
- **User-specific Equipments:** Fetch equipment added by a specific user based on their email.
- **Category-specific Equipments:** Fetch all equipment under a specific category.
- **Add Equipment:** Add new equipment to the database.
- **Update Equipment:** Update details of an existing equipment item.
- **Delete Equipment:** Delete an equipment item from the database.

## Technologies Used

- **Node.js**: Backend runtime.
- **Express.js**: Web framework for creating RESTful APIs.
- **MongoDB**: Database for storing equipment data.
- **dotenv**: Environment variable management.
- **cors**: Cross-origin resource sharing.
